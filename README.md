# Jean Paul Saucedo — Portfolio

Bilingual portfolio for a Senior Full-Stack Developer, built as a static Astro site.

## Live site

The portfolio is deployed on Cloudflare: [portafolio-jpsg.jpscorp21.workers.dev](https://portafolio-jpsg.jpscorp21.workers.dev/).

## Development

```sh
npm install
npm run dev
```

Use `astro dev --background` when running the server through Codex, as described in `AGENTS.md`.

## Content and design

- Read `DESIGN.md` before changing the interface.
- See `docs/content-guide.md` to add projects, update translations, or replace the CV.
- The current implementation plan and pending content are in `plans/portfolio-v1.md`.

## Checks

```sh
npm run build
npm run astro check
```

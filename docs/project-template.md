# Project template

Copy the frontmatter below into a new file under `src/content/projects/`. Do not place the template itself in the collection.

```yaml
---
order: 5
featured: true
image: /images/projects/project-name.jpg
imagePosition: center
imageFit: cover
technologies:
  - TypeScript
es:
  title: Nombre del proyecto
  description: Qué problema resuelve.
  detail: Cómo funciona o cuál fue tu aporte.
en:
  title: Project name
  description: The problem it solves.
  detail: How it works or what you contributed.
# demoUrl: https://example.com
# repositoryUrl: https://github.com/example/project
---
```
